Заглушки спрайтов

Пустые холсты правильного размера с разметкой кадров — чтобы рисовать поверх, а не вымерять сетку заново. Розовая рамка и номер в углу кадра вшиты в PNG: это мусор, его надо стереть.

Пока в игре их не видно

У большинства классов стоит public override string Texture => "Terraria/Images/…" — подмена ванильным спрайтом. Пока строка на месте, tModLoader берёт ванильную текстуру, а не соседний PNG. В карточке ниже указан файл и строка: снимай подмену по мере готовности рисунка, по одной.

Зум
Сетка пикселей
Тема
Общее правило: PNG с альфой, фон полностью прозрачный, края без полупрозрачного сглаживания — пиксель либо есть, либо нет. Имена файлов и регистр букв менять нельзя, код ищет их буква в букву.
Не сошёлся размер после отрисовки — не подгоняй рисунок, скажи: подстроить код под лист дешевле.
Стены глубин (Tidestone_wall, Tidesand_wall, Tidestone_wall_cracked) заглушек не получили: у стен раскладка листа отличается от тайлов, и её надо сверять с ванильной стеной в коде. Заглушка с выдуманной сеткой хуже, чем её отсутствие.
