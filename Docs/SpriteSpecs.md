# Что рисовать — точные раскладки

Общее для всех файлов: PNG с альфой, фон полностью прозрачный (не белый и не чёрный),
края без полупрозрачного сглаживания — пиксель либо есть, либо нет. Имена файлов и
регистр букв менять нельзя, код ищет их буква в букву.

Если после отрисовки размер не сошёлся с указанным — не подгоняй, скажи мне: подстроить
код под лист дешевле, чем перерисовывать.

## 1. Приливная флора — `Content/Tiles/Nature/Tidekelp_tile.png`

**Лист 398 × 52.** Сетка 8 столбцов × 3 ряда, клетка **48 × 16**, шаг 50 по X и 18 по Y
(между клетками 2 px пустоты; справа и снизу отступа нет — стандарт листа тайлов Terraria).

**Клетка шире тайла втрое.** Тайл — это только центральные 16 px клетки (x = 16…31),
лапы уходят за них влево и вправо и свисают на соседние тайлы. На проходимость это не
влияет — свисает один рисунок. На холсте-заглушке границы тайла отмечены розовым
пунктиром, ось стебля — белым.

Ряд (TileFrameY) — вид, столбец (TileFrameX) — форма сегмента:

```
          0        1        2        3        4        5        6        7
        комель   стебель  лапа L   лапа L   лапа R   лапа R   лапы     верхушка
                          длинн.   коротк.  длинн.   коротк.  в обе
      +--------+--------+--------+--------+--------+--------+--------+--------+
y=0   |        |        |        |        |        |        |        |        |  ель
      +--------+--------+--------+--------+--------+--------+--------+--------+
y=18  |        |        |        |        |        |        |        |        |  папоротник
      +--------+--------+--------+--------+--------+--------+--------+--------+
y=36  |        |        |        |        |        |        |        |        |  рыжий куст
      +--------+--------+--------+--------+--------+--------+--------+--------+
```
x = 0, 50, 100, 150, 200, 250, 300, 350

**Виды (ряды).**

- **Ряд 0 — ель.** Несущий вид Чёрных лесов: тёмная, почти чёрная хвоя, силуэт как у
  подводной ели с референса, редкие красно-розовые вкрапления на лапах. Высота в мире
  12–110 сегментов, стебель тянется от пола зала до свода.
- **Ряд 1 — папоротник.** Подлесок: светлее и холоднее ели, сине-зелёный, лапы шире и
  реже, перистые. Высота 6–26.
- **Ряд 2 — рыжий куст.** Акцент у самого дна: тёплый рыже-оранжевый, плотный, короткие
  жёсткие лапы. Высота 3–7 — это всегда низкий кустик, вытянуться он не может.

**Обязательные требования к рисунку.**

- **Стыковка по вертикали.** У столбцов 0–6 стебель обязан доходить до верхней и нижней
  грани клетки и совпадать по X: сегменты стоят друг на друге вплотную, иначе будет
  разрыв. Держи стебель шириной 6–10 px по центру клетки (центр по X = 24).
- **Точка качания — середина нижней грани тайла, то есть (24, 16) в координатах клетки.**
  Сегмент кренится вокруг неё, размах растёт к верхушке. «Корень» рисунка должен быть
  внизу по центру, иначе при качании стебель разъедется.
- **Столбец 0 (комель)** снизу упирается в грунт — низ можно рисовать свободно, утолщением.
- **Столбец 1 (голый стебель)** — просвет в кроне, без лап. Генератор ставит его примерно
  каждый пятый сегмент, чтобы заросли просматривались насквозь.
- **Столбцы 2–5 — лапы.** Пара «длинная / короткая» на каждую сторону нужна для разнобоя;
  стороны генератор чередует сам. Длинная лапа может доходить до края клетки (16 px за
  границу тайла), короткая — примерно до половины.
- **Столбец 6** — лапы в обе стороны, ставится только в нижней половине стебля.
- **Столбец 7 (верхушка)** снизу стыкуется со стеблем, сверху свободна. Верхушка ярче
  остальных сегментов: на ней держится биолюминесценция, цепочка огоньков по кронам
  показывает высоту зала.

Один и тот же сегмент повторяется подряд до сотни раз — приметных деталей, которые
будут читаться как повтор, избегай; разнообразие даёт чередование столбцов, а не рисунок
внутри клетки.

## 2. Рыцарь-краб — `Content/NPCs/Bosses/KingCrab/CrabKnight.png` — СДЕЛАНО

**Лист 66 × 288.** Кадры идут вертикально, **без отступов между ними**: кадр 66 × 48,
кадров 6, 48 × 6 = 288.

```
y=0    кадр 0 — стойка
y=48   кадр 1
y=96   кадр 2
y=144  кадр 3     кадры 1..5 — цикл ходьбы
y=192  кадр 4
y=240  кадр 5
```

- Рисунок занимает 66 × 46 внутри кадра и стоит на его нижней грани.
- Хитбокс в коде 52 × 36 — уже рисунка: по краям кадра разведённые ноги и клешня,
  попадать по ним нечестно. Спрайт поднят на 4 px через `DrawOffsetY`, иначе ванильная
  отрисовка сажает его в грунт.
- Спрайт нарисован мордой ВПРАВО. Ваниль отражает NPC при `spriteDirection == 1`,
  поэтому в коде стоит инверсия (`spriteDirection = -direction`). Если перерисуешь
  мордой влево — скажи, сниму инверсию.

### Полный лист с анимациями атак — 66 × 1152

Кадры по-прежнему одной колонкой, кадр 66 × 48, без отступов. Всего 24 кадра:
номер кадра = `y / 48`. Код уже считает число кадров по самому файлу, поэтому
как только положишь лист на 24 кадра — анимации включатся сами, править ничего не надо.
Пока лежит шестикадровый лист, работает старое поведение (0 стойка, 1–5 ход).

| Кадры | y | Анимация | Как играется |
|---|---|---|---|
| 0–1 | 0, 48 | стойка | петля, 14 тиков на кадр |
| 2–7 | 96–336 | ход | петля, скорость от движения |
| 8–9 | 384, 432 | замах щитом | один раз, 11 тиков |
| 10–11 | 480, 528 | удар щитом | один раз, 6 тиков |
| 12–14 | 576–672 | подготовка тарана | один раз, 9 тиков |
| 15–17 | 720–816 | таран | петля, 4 тика |
| 18–20 | 864–960 | оглушение | петля, 10 тиков |
| 21 | 1008 | взлёт | держится, пока летит вверх |
| 22 | 1056 | падение | держится, пока падает |
| 23 | 1104 | приземление | один раз |

Что должно читаться в каждой группе:

- **Замах щитом** — корпус уходит назад, щит вперёд. Игрок должен успеть отойти.
- **Удар щитом** — резкий выпад вперёд, щит на всю ширину кадра.
- **Подготовка тарана** — приседает, роет грунт задней ногой, щит вжат в плечо.
  Это самая важная поза: после неё либо таран, либо (в четверти случаев) прыжок,
  и обманка работает только если поза читается однозначно.
- **Таран** — вытянут в линию, ноги подобраны, щит впереди корпуса.
- **Оглушение** — щит опущен, корпус завален вбок, ноги врозь. Единственное окно
  уязвимости, поза обязана отличаться от всех остальных с одного взгляда.
- **Взлёт / падение / приземление** — ноги поджаты в воздухе, раскинуты при ударе о землю.

## 2а. Краб-маг — `Content/NPCs/Bosses/KingCrab/CrabMage.png`

**Лист 66 × 288** — точно та же раскладка, что у паладина: кадр 66 × 48, 6 кадров
вертикально без отступов, кадр 0 стойка, 1–5 ходьба, краб стоит на нижней грани кадра.

Отличаться он должен не размером, а силуэтом и цветом: паладин багровый и приземистый,
маг — холодная бирюза (`#2E7E8C` тень, `#46B0C4` средний, `#8FE4F2` блик), выше в посадке,
одна клешня меньше и держит что-то светящееся. Хитбокс в коде 44 × 34, то есть корпус
уже, чем у паладина.

Пока своего листа нет, маг рисуется листом паладина с бирюзовым тинтом в `GetAlpha`.
Как появится файл — уберу и подмену текстуры, и тинт.

### Полный лист мага — 66 × 912

19 кадров одной колонкой, кадр 66 × 48. Считается по файлу так же, как у паладина.

| Кадры | y | Анимация | Как играется |
|---|---|---|---|
| 0–1 | 0, 48 | стойка | петля, 14 тиков |
| 2–7 | 96–336 | ход | петля, скорость от движения |
| 8–10 | 384–480 | сбор залпа | один раз, 8 тиков |
| 11–12 | 528, 576 | выстрел | один раз, 5 тиков |
| 13–15 | 624–720 | канал гейзера | петля, 7 тиков |
| 16–18 | 768–864 | уход в песок | один раз, 6 тиков |

- **Сбор залпа** — клешня поднята, вокруг неё копится свет.
- **Выстрел** — клешня выброшена вперёд.
- **Канал гейзера** — обе клешни вниз, корпус согнут: он тянет воду из грунта,
  и поза должна отличаться от залпа, иначе игрок не поймёт, куда смотреть.
- **Уход в песок** — три стадии погружения: целый, по пояс, одна макушка.
  Тот же клип играется задом наперёд при всплытии, отдельные кадры не нужны.

## 8. Стены глубин

`Content/Walls/Tidestone_wall.png`, `Tidesand_wall.png`, `Tidestone_wall_cracked.png`.

**Лист 468 × 252 каждый.** Сетка 13 столбцов × 7 рядов, шаг ячейки **36 × 36**,
но рисуется из ячейки только левый верхний квадрат **32 × 32** — остальные 4 px по правому
и нижнему краю ячейки движок не читает, это разделитель.

Раскладка сверена по коду игры, не по памяти: `Terraria.Framing.Initialize` задаёт
`wallFrameSize = 36 × 36` и таблицу `wallFrameLookup[style][num]` с индексами ячеек
до 12 по X и до 6 по Y; `WallDrawing.DrawWalls` берёт из листа прямоугольник 32 × 32.

Почему 32, а не 16: стена рисуется со смещением −8, −8 от своего тайла, то есть каждый
кусок вылезает на 8 px во все стороны и подлезает под соседние блоки. Значит рисунок
в ячейке обязан быть цельным на все 32 px, а не 16-пиксельной картинкой в углу.

- **Столбец = вариант соседства** (`style`): какие из четырёх соседей — тоже стена.
  Углы, кромки, торцы. Ряды 0–4 в основном заняты этими вариантами.
- **Ряд внутри столбца = случайный вариант** (`num`, 0–2): три непохожих версии одного
  и того же куска, чтобы кладка не читалась повтором. Три версии обязательны:
  движок берёт номер случайно при генерации и запоминает его в тайле.
- Ячейки столбцов 9–12 и ряда 5–6 — варианты для сплошного массива (все четыре соседа есть).
  Это самая частая ячейка в игре: именно она заполняет глубину, ей уделить больше всего сил.

**Стыковка:** соседние куски стыкуются по границе 32 px, а не 16 — проверяй рисунок
на разрыв не по краю ячейки, а по линии, где два куска накладываются.

Пока своих листов нет, классы подменяют текстуру ванильной (`Wall_1` камень,
`Wall_216` затвердевший песок, `Wall_94` плита подземелья) — снимается строкой
`public override string Texture` в `Content/Walls/*.cs`.

Проще всего начать с `Tidestone_wall`: он закрывает всю глубину зон 3–5.
`Tidesand_wall` идёт за песчаными наносами, `Tidestone_wall_cracked` — рукотворная
кладка, из неё набрана коралловая арка.

## 9. VFX-текстуры для шейдеров и свечений — `Assets/Textures/Vfx/`

Общие правила для всех текстур этого раздела:
- **Белым (или оттенками серого) по прозрачному.** Цвет задаёт код: одна и та же
  текстура светится и синей водой, и красной яростью краба. Цветная текстура этот цвет
  испортит.
- **Яркость = альфа.** Рисуются аддитивно, поэтому важна только форма яркости: где
  пиксель плотнее, там свет сильнее. Полностью прозрачное не светится.
- **Мягко, без жёстких краёв и без лучей.** Растягиваются в 2–10 раз, любой пиксельный
  край превратится в ступеньку, любой луч — в звезду (так и выглядит сейчас: всё рисуется
  звездой `BeamDistortion.png`).
- **Край листа полностью прозрачен** — хотя бы 2 px по периметру, иначе при
  растяжении проступит квадрат.
- Размеры — степени двойки, как указано. Больше не нужно: текстура всё равно мылится.

Пока файла нет, код рисует старой звездой — ничего не ломается. Положил файл и
пересобрал мод — эффект подхватит его сам, в коде ничего менять не надо.

### 9.1 `SoftGlow.png` — 128 × 128, мягкое круглое пятно — ЕСТЬ (26.09)

Радиальный градиент: в центре альфа 100%, к краю плавно в 0, **к радиусу ~30 px уже ноль**.
Спад не линейный, а «колоколом»: яркое ядро примерно в четверть диаметра и длинный
мягкий хвост. Никаких колец, лучей, шума.

Где используется (`SoAVfx.DrawTintedGlow`): свечение на острие копья, капли-счётчик
шквала, капли водяной верёвки, пульсы и ауры Короля-краба, блики снарядов.

### 9.2 `SoftStreak.png` — 256 × 64, мягкий горизонтальный штрих — ЕСТЬ (26.09)

Вытянутое пятно вдоль оси X. Поперёк (по Y) — тот же «колокол», что у SoftGlow: яркая
тонкая линия по центру в 2–4 px и мягкое гало до краёв. Вдоль (по X) — к обоим концам
плавно гаснет, самые яркие — средние ~60% длины. Горизонталь обязательна: код
поворачивает штрих сам.

Где используется (`SoAVfx.DrawTintedQuad`, `DrawTravellingArcs`): ореол вдоль древка
копья, блик на пике удара, дуги разгона на броске, линии рывка, трещины и столбы света
у Короля-краба.

### 9.3 `TrailNoise.png` — 512 × 256, шум для ленты-трейла — ЕСТЬ, подключён (26.09)

Сейчас лента `SoATrail` (след за острием копья, водяное лезвие) берёт общий
`WaveNoise.png`. Своя текстура сделает её красивее. Что нужно: длинные горизонтальные
прожилки-струи разной толщины и яркости, серым по чёрному (**здесь фон НЕ прозрачный**,
шейдер читает яркость). **Бесшовно по обеим осям** — шум бежит по кругу.
Если нарисуешь — скажи, подключу (одна строка в `SoATrail.cs`).

### 9.4 `TeleportReticle.png` — 64 × 64, прицел приливного рывка — ЕСТЬ (26.09)

Заменяет курсор, пока у Королевской Регалии полная шкала прилива и зажата ПКМ.
Белым по прозрачному: код красит его голубым (рывок возможен) или красным (на пути
стена / нет места) и медленно вращает, поэтому рисунок должен хорошо смотреться под
любым углом. На экране он ~40 px.

Что на нём: тонкое кольцо радиусом ~24 px с четырьмя разрывами или засечками
на 12, 3, 6 и 9 часах и маленькая точка в центре. Края мягкие в 1–2 px, без
пиксельной лесенки. 2 px по краю листа прозрачны.

Пока файла нет, прицел собирается из четырёх штрихов `SoftStreak` и точки `SoftGlow`.
